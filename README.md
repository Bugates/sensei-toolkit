# Sensei website — GitHub Pages build

This folder is ready to publish from the root of the `Bugates/sensei-toolkit` repository.

1. Push every file and folder in this directory to the repository's `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose **main**, select **/(root)**, and click **Save**.

The site will appear at:

https://bugates.github.io/sensei-toolkit/

The relative asset paths in this build allow the JavaScript, styles, downloads, and STL files to load correctly from the `sensei-toolkit` repository subdirectory.
